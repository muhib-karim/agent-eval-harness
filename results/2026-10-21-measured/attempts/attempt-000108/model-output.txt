The bug is in `merge()`. It adds the two `_m2` values but leaves out the between-group term from the parallel (Chan et al.) formula:

M2 = M2_a + M2_b + delta² · n_a · n_b / n

I also checked the edge cases:

- If one side is empty, `delta` would be computed from a mean of 0.0. The cross term is zero because `n_a * n_b = 0`, and the mean formula gives the other side's mean exactly. Even so, I copy the non-empty side directly, which is cleaner and exact.
- `delta * other._n / n` is kept for the mean, since it is stable.

Check against the reproduction: delta = 11 − 2 = 9, so the cross term is 81·3·3/6 = 121.5. Each side has M2 = 2, so the total is 125.5, and 125.5/5 = 25.1. ✓

```python
"""Streaming mean and sample variance (Welford), mergeable across shards."""

import math


class RunningStats:
    def __init__(self):
        self._n = 0
        self._mean = 0.0
        self._m2 = 0.0

    def push(self, x):
        if isinstance(x, bool) or not isinstance(x, (int, float)) or not math.isfinite(x):
            raise ValueError("x must be a finite number")
        self._n += 1
        delta = x - self._mean
        self._mean += delta / self._n
        self._m2 += delta * (x - self._mean)

    @property
    def count(self):
        return self._n

    @property
    def mean(self):
        if self._n < 1:
            raise ValueError("mean needs at least one value")
        return self._mean

    @property
    def variance(self):
        if self._n < 2:
            raise ValueError("variance needs at least two values")
        return self._m2 / (self._n - 1)

    @property
    def stdev(self):
        return math.sqrt(self.variance)

    def merge(self, other):
        result = RunningStats()
        if self._n == 0 and other._n == 0:
            return result
        if other._n == 0:
            result._n = self._n
            result._mean = self._mean
            result._m2 = self._m2
            return result
        if self._n == 0:
            result._n = other._n
            result._mean = other._mean
            result._m2 = other._m2
            return result
        n = self._n + other._n
        delta = other._mean - self._mean
        result._n = n
        result._mean = self._mean + delta * other._n / n
        result._m2 = self._m2 + other._m2 + delta * delta * self._n * other._n / n
        return result
```
