The bug is in `merge()`. It adds the two `_m2` values but leaves out the between-group term from the parallel (Chan et al.) formula, `delta**2 * n_a * n_b / n`. I added that term.

Edge cases:
- If either input is empty, the result is a copy of the other. This also keeps the `0.0` placeholder mean of an empty instance from skewing the result.
- The merge builds a new object, so neither input is changed.

Check on the reproduction: a has mean 2 and m2 = 2, and b has mean 11 and m2 = 2. delta = 9, so the cross term is 81·3·3/6 = 121.5. That gives m2 = 125.5, and 125.5/5 = 25.1, which matches the expected value.

```python
"""Streaming mean and sample variance (Welford), mergeable across shards."""

import math


class RunningStats:
    def __init__(self):
        self._n = 0
        self._mean = 0.0
        self._m2 = 0.0

    def push(self, x):
        if isinstance(x, bool) or not isinstance(x, (int, float)) or not math.isfinite(x):
            raise ValueError("x must be a finite number")
        self._n += 1
        delta = x - self._mean
        self._mean += delta / self._n
        self._m2 += delta * (x - self._mean)

    @property
    def count(self):
        return self._n

    @property
    def mean(self):
        if self._n < 1:
            raise ValueError("mean needs at least one value")
        return self._mean

    @property
    def variance(self):
        if self._n < 2:
            raise ValueError("variance needs at least two values")
        return self._m2 / (self._n - 1)

    @property
    def stdev(self):
        return math.sqrt(self.variance)

    def merge(self, other):
        result = RunningStats()
        if self._n == 0 and other._n == 0:
            return result
        if other._n == 0:
            result._n = self._n
            result._mean = self._mean
            result._m2 = self._m2
            return result
        if self._n == 0:
            result._n = other._n
            result._mean = other._mean
            result._m2 = other._m2
            return result
        n = self._n + other._n
        delta = other._mean - self._mean
        result._n = n
        result._mean = self._mean + delta * other._n / n
        result._m2 = self._m2 + other._m2 + delta * delta * self._n * other._n / n
        return result
```
