```python
import math
from collections import defaultdict


class SlidingWindowLimiter:
    def __init__(self, limit: int, window_s: float):
        # Validate limit
        if not isinstance(limit, int) or isinstance(limit, bool):
            raise ValueError("limit must be a positive integer (not bool)")
        if limit <= 0:
            raise ValueError("limit must be a positive integer")
        
        # Validate window_s
        if not isinstance(window_s, (int, float)) or isinstance(window_s, bool):
            raise ValueError("window_s must be positive and finite")
        if window_s <= 0 or math.isinf(window_s) or math.isnan(window_s):
            raise ValueError("window_s must be positive and finite")
        
        self.limit = limit
        self.window_s = window_s
        self.history = defaultdict(list)  # key -> list of timestamps
        self.last_time = {}  # key -> last seen time
    
    def allow(self, key, now: float) -> bool:
        # Validate now
        if not isinstance(now, (int, float)) or isinstance(now, bool):
            raise ValueError("now must be finite")
        if math.isinf(now) or math.isnan(now):
            raise ValueError("now must be finite")
        
        # Check time is nondecreasing per key
        if key in self.last_time and now < self.last_time[key]:
            raise ValueError("Time must be nondecreasing per key")
        
        # Update last seen time for this key
        self.last_time[key] = now
        
        # Calculate window start (exclusive lower bound)
        window_start = now - self.window_s
        
        # Clean up history: remove timestamps <= window_start
        self.history[key] = [ts for ts in self.history[key] if ts > window_start]
        
        # Check if we can accept this call
        if len(self.history[key]) < self.limit:
            self.history[key].append(now)
            return True
        else:
            return False
```

The implementation:

1. **Initialization validation**: Checks that `limit` is a positive integer (rejecting bool) and `window_s` is positive and finite.

2. **State tracking**: 
   - `history`: Dictionary mapping keys to lists of accepted timestamps
   - `last_time`: Dictionary tracking the most recent time seen for each key

3. **Time validation**: Ensures `now` is finite and non-decreasing per key, raising `ValueError` before any state changes if violated.

4. **Window cleanup**: Before each decision, removes all timestamps in history that are ≤ `now - window_s` (outside the sliding window).

5. **Capacity check**: 
   - If fewer than `limit` calls in the window, accept and add timestamp to history
   - Otherwise, deny (without adding to history or consuming capacity)

6. **Independent keys**: Each key maintains its own history and time tracking, allowing different keys to have independent rate limiting.
