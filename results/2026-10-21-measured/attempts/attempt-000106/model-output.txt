The bug is in `merge()`: it adds the two `_m2` values but leaves out the between-group term. With Chan's parallel algorithm, `M2 = M2a + M2b + delta² * na * nb / n`.

The fix also covers the case where one side is empty. If `other._n == 0`, the delta is computed from a mean of 0.0 and the formula still works, since `delta * 0 / n` is 0 and the cross term is 0. But if `self._n == 0`, `self._mean` is 0.0, so the result mean is `0 + delta * other._n / n = other._mean`, which is right, though not exact in floating point. I copy the non-empty side directly in those cases to keep the result exact.

```python
"""Streaming mean and sample variance (Welford), mergeable across shards."""

import math


class RunningStats:
    def __init__(self):
        self._n = 0
        self._mean = 0.0
        self._m2 = 0.0

    def push(self, x):
        if isinstance(x, bool) or not isinstance(x, (int, float)) or not math.isfinite(x):
            raise ValueError("x must be a finite number")
        self._n += 1
        delta = x - self._mean
        self._mean += delta / self._n
        self._m2 += delta * (x - self._mean)

    @property
    def count(self):
        return self._n

    @property
    def mean(self):
        if self._n < 1:
            raise ValueError("mean needs at least one value")
        return self._mean

    @property
    def variance(self):
        if self._n < 2:
            raise ValueError("variance needs at least two values")
        return self._m2 / (self._n - 1)

    @property
    def stdev(self):
        return math.sqrt(self.variance)

    def merge(self, other):
        result = RunningStats()
        n = self._n + other._n
        if n == 0:
            return result
        if other._n == 0:
            result._n = self._n
            result._mean = self._mean
            result._m2 = self._m2
            return result
        if self._n == 0:
            result._n = other._n
            result._mean = other._mean
            result._m2 = other._m2
            return result
        delta = other._mean - self._mean
        result._n = n
        result._mean = self._mean + delta * other._n / n
        result._m2 = self._m2 + other._m2 + delta * delta * self._n * other._n / n
        return result
```
