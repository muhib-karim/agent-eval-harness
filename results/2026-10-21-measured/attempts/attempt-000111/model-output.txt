The bug is in the regex: `[^a-z0-9]` matches one character at a time, so each non-alphanumeric character becomes its own dash. Adding `+` makes each run collapse into a single dash.

Truncation is already safe. The slug has no consecutive dashes before it is cut, and `rstrip("-")` removes any dash left at the end of the cut.

```python
"""URL slugs from arbitrary titles."""

import re
import unicodedata


def slugify(text, max_length=None):
    if not isinstance(text, str):
        raise TypeError("text must be str")
    if max_length is not None and (type(max_length) is not int or max_length < 1):
        raise ValueError("max_length must be an int >= 1")
    ascii_text = unicodedata.normalize("NFKD", text).encode("ascii", "ignore").decode("ascii")
    slug = re.sub(r"[^a-z0-9]+", "-", ascii_text.lower()).strip("-")
    if max_length is not None:
        slug = slug[:max_length].rstrip("-")
    return slug
```
