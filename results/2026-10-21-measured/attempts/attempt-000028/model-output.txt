The implementation below uses a dynamic-programming table restricted to a diagonal band. When there is no `max_distance`, the band covers the whole table.

1. **Input checks.** Non-`str` inputs raise `TypeError`. A `max_distance` that is negative, a `bool`, or not an `int` raises `ValueError`.

2. **Trimming.** A shared prefix and suffix never change the distance, so they are removed first.

3. **Memory.** The strings are swapped so that `b` is the shorter one. Only two rows of length `len(b) + 1` are kept, which gives O(min(len(a), len(b))) extra memory.

4. **Banding.** With a limit `k`, only cells where `|i - j| <= k` can hold a value `<= k`. Each row therefore computes just those positions, so the cost is about `len(a) * (2k + 1)`. For two 20,000-character strings with a small `k`, that is fast.
   - The cells just outside the band are set to a sentinel `k + 1`, so stale values are never read.
   - Values are capped at `k + 1`.

5. **Early exits.**
   - If the length difference already exceeds `k`, the function returns `k + 1` immediately.
   - If a whole row's minimum exceeds `k`, it also stops early with `k + 1`.

6. **Unbounded case.** Without a limit, `k = len(a)` (the longer string), so the band covers the whole table. Two 1,000-character strings then take about 10⁶ cell updates.

```python
def levenshtein(a, b, max_distance=None):
    if not isinstance(a, str) or not isinstance(b, str):
        raise TypeError("a and b must be str")
    if max_distance is not None:
        if isinstance(max_distance, bool) or not isinstance(max_distance, int):
            raise ValueError("max_distance must be a non-negative int")
        if max_distance < 0:
            raise ValueError("max_distance must be a non-negative int")

    if a == b:
        return 0

    # Strip common prefix
    start = 0
    la, lb = len(a), len(b)
    lim = min(la, lb)
    while start < lim and a[start] == b[start]:
        start += 1
    # Strip common suffix
    ea, eb = la, lb
    while ea > start and eb > start and a[ea - 1] == b[eb - 1]:
        ea -= 1
        eb -= 1
    a = a[start:ea]
    b = b[start:eb]

    # Ensure b is the shorter string (memory O(len(b)))
    if len(a) < len(b):
        a, b = b, a
    m, n = len(a), len(b)

    if max_distance is not None:
        k = max_distance
        if m - n > k:
            return k + 1
    else:
        k = m

    if n == 0:
        return m  # m - n <= k guaranteed here

    big = k + 1
    prev = [j if j <= k else big for j in range(n + 1)]
    cur = [big] * (n + 1)

    for i in range(1, m + 1):
        ca = a[i - 1]
        lo = i - k
        if lo < 1:
            lo = 1
        hi = i + k
        if hi > n:
            hi = n
        if lo == 1:
            first = i if i <= k else big
        else:
            first = big
        cur[lo - 1] = first
        rowmin = first
        left = first
        for j in range(lo, hi + 1):
            cost = prev[j - 1] + (ca != b[j - 1])
            x = prev[j] + 1
            if x < cost:
                cost = x
            x = left + 1
            if x < cost:
                cost = x
            if cost > big:
                cost = big
            cur[j] = cost
            left = cost
            if cost < rowmin:
                rowmin = cost
        if hi < n:
            cur[hi + 1] = big
        if rowmin > k:
            return big
        prev, cur = cur, prev

    result = prev[n]
    return result if result <= k else big
```
